# Irreplaceable

Marks one-time items in World of Warcraft: Forever. The item tooltip says what it is and why it matters. Looting one shows a notice. The right quest reward is marked, and a quest that destroys the item asks before you turn it in.

In-game text follows the client language. English and German are included. Commands stay English: `/irreplaceable` and `/irr`.

Copy the `Irreplaceable` folder into `Interface/AddOns`. A new folder needs a full client restart. Later Lua edits load with `/reload`.

The addon loads only on Forever.
